MacClean 1.1.0：连续清理更顺手，磁盘占用更清晰。

- 清理后保留扫描结果、浏览位置与剩余勾选，不再清空存储、应用和重复文件页。
- 仅更新受影响的文件与目录；恢复后文件也会重新出现在已有结果中。
- 空间概览改为双层环形图：内圈是当前目录，外圈是下一层内容。支持悬停查看大小、点击扇区下钻、返回上层及查看最大的五个文件。
- 更新为石墨灰、白色与蓝紫色配色，文件夹使用不同颜色区分。
- 侧栏整行（图标、文字及留白）都能点击，并加入悬停反馈。
- 29 项核心回归检查与 19 项真实界面操作检查通过，包含连续两次清理与恢复。

支持 macOS 13+，安装包包含 Apple Silicon 与 Intel 架构。Intel 已经 Rosetta 启动验证，未在 Intel 硬件验证。

当前版本为 ad-hoc 临时签名，未经 Apple Developer ID 签名与公证。文件先移到废纸篓，清空废纸篓后才释放空间。
