MacClean 首个开源版本，原生 SwiftUI 中文界面，支持 macOS 13+。

- 存储分析：按文件与文件夹统计、逐层浏览、大小排序、搜索及大文件筛选。
- 应用占用：应用本体与 Bundle ID 精确匹配的关联数据，可预览卸载。
- 垃圾整理：旧缓存、日志、Xcode 构建缓存、旧安装包与旧下载。
- 重复文件：SHA-256 内容比对，每组保留一份。
- 恢复记录：移到废纸篓、恢复原位置、同名文件保护。
- 白底简约线条垃圾桶图标；无第三方依赖、无遥测。

下载 `MacClean-1.0.0-universal.dmg`，拖入 Applications。Universal 2 同时包含 Apple Silicon 与 Intel；Intel 未经实机验证。源码可使用同一版本标签下载，额外附带源码 ZIP 与 SHA-256 校验清单。

**签名说明：** 此版本为 ad-hoc 临时签名，未经 Apple Developer ID 签名与公证。macOS 可能提示无法验证开发者；确认来源和校验值后，可在「系统设置 → 隐私与安全性」允许打开。

**清理说明：** 所选文件先移到废纸篓，清空废纸篓后才释放空间。个人下载、安装包、开发缓存和应用关联数据默认不勾选。权限不足和 APFS 特性会影响统计；详见中文 README。
